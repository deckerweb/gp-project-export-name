Changelog

2.0.0 · 2026-10-27

New

  • Configure project names, filename patterns and language variants on a dedicated settings page, with project search and a live preview.
  • Use backup, reviewed import and selective reset tools; open the five-step quick guide at any time.
  • Includes the deckerweb Library and validated GitHub updates.

Improved

  • Use the exported translation’s language, distinguish formal and custom sets, and prevent filename collisions within a project.
  • Choose responsibility when other recognized filename plugins are active.
  • Adds accessible bilingual documentation, illustrated instructions and the plugin icon.

Fixed

  • Keep the original GlotPress filename when a generated name is invalid; preserve export contents and compound file extensions.

Misc

  • Requires WordPress 6.4, PHP 8.1 and GlotPress 4.0 or newer. Settings belong to each website and remain after uninstall.
  • From version 2018.09.15, upload the ZIP and confirm replacement because WordPress compares the old date-based version as newer.

Improved

Fixed

  • Restored export filenames.
